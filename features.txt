AC8 VR features — November 2026 community preview

- Move and resize the cockpit HUD by group. Adjust the ladder, radar,
  aircraft status, mission information and wingman status. Trim the
  flight path marker independently while it follows the ladder.
- Save HUD layouts and UI size per aircraft. Save cockpit camera position
  and perceived cockpit size separately or with the HUD. Set global defaults.
- See the game's HUD glow in VR, with glow applied selectively during flight.
- Read world target labels more easily and use smaller off-screen indicators.
- Get cleaner loading transitions, improved cinematic and hangar framing,
  readable tutorial cards, and single-step pause and retry navigation.
- Enable only the enhancements you want. Core stays enabled and the seven
  optional Lua modules can be disabled individually.

Requires UEVR, OpenXR and Native Stereo. Restart after changing the game
resolution or UEVR render resolution.
